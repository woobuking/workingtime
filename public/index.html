Apps Script URL 등록

Google Sheets의 Apps Script 웹앱 URL을 등록해주세요.
최초 1회만 입력하면 됩니다.

1 Google Sheets 열기 → 확장 프로그램 > Apps Script
2 Code.gs 내용을 붙여넣고 저장
3 배포 > 새 배포 → 유형: 웹 앱
실행: 나 / 액세스: 모든 사람
4 웹 앱 URL을 아래에 붙여넣기
